🔍 Key Insights
- Males spend more time on social media (615hrs vs 585hrs)
- Instagram users show highest anxiety levels (2330)
- Only 2.58% of students classified as depressed
- Higher screen time correlates with increased stress
- Students sleeping 4-5 hours show highest depression risk

🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Slicers
- VBA Macros

⚙️ Features
- 5 interactive charts with slicer-based filtering
- 2 KPI cards for quick insights
- Auto-refresh macro for data updates
- One-click PDF export
- Filter reset button
- Last refreshed timestamp
